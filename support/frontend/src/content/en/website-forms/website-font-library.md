Super Admin maintains the **shared font library** used by every company website.

## Open the font library

1. Sign in to **Design** as Super Admin.
2. In the left menu, open **Website** → **Fonts**.

## List and search

The page lists every active font in the library with a preview. Use the search box to filter by name or font family.

## Add a font

1. Click **Add font**.
2. Enter a **style name** (how the font appears in lists).
3. Paste the **Google Font stylesheet URL** or full `<link>` tag from [Google Fonts](https://fonts.google.com/).
4. Confirm the **font family** was detected, then click **Save**.

The font is available immediately when company admins choose **From library** while adding a font to a theme.

## Remove a font

1. Open the row menu (three dots) for the font.
2. Choose **Delete** and confirm.

Removing a font hides it from the library picker. Themes that already use the font are not changed.

See also [Website themes](website-themes.md).
