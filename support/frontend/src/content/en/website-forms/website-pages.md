1. Open **Design → Website** (pages). Registering a company adds default pages, layouts, headers, footers, presets, datasets, and a theme. Those default items stay in place: use **Duplicate**, then edit the copy. The default home page shows the company name, a short welcome line, and a Get in touch button.
2. Add a page or open an existing one. Choose a **layout** so the page uses that header, footer, theme, and nav menu.
3. Use the page designer to add content, then save.
4. Open the live site from the company profile **Website** URL, or use Preview / Browse in Design.
5. Company admins can choose **Add from library** on pages, layouts, headers, footers, or presets. That adds a copy to this website. Editing the copy does not change the shared library, and later library edits do not change copies already added. Themes use **Add theme**, which opens the theme detail page.
6. Super Admin maintains that library under **Design → Website** (pages, layouts, headers, footers, and presets).

Pair pages with a [layout](/docs/website-forms/website-layouts), [headers and footers](/docs/website-forms/headers-footers), and a [theme](/docs/website-forms/website-themes). Reuse designed content elements with [website presets](/docs/website-forms/website-presets). Share the public address from [Public company site URL](/docs/website-forms/public-site-url).
