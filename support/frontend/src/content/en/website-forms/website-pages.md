1. Open **Website → Pages**. Registering a company adds default pages, layouts, headers, footers, presets, datasets, and a theme. Those default items stay in place: use **Duplicate**, then edit the copy. The default home page shows the company name, a short welcome line, and a Get in touch button.
2. Open an existing page, or choose **Add page**. Then pick **Add from library** to copy a shared page, or **Create new** to make one for this website. Choose a **layout** so the page uses that header, footer, theme, and nav menu. Super Admin uses **Add page** to add a library page directly.
3. Use the page designer to add content, then save.
4. Open the live site from the company profile **Website** URL, or use Preview / Browse in Website.
5. On Pages, Layouts, Headers, Footers, Presets, and Themes, **Add** asks whether to **Add from library** or **Create new**. Add from library copies a shared item into this website and keeps a link to that library item. The copy is marked **From library**. Company admins can edit it in the designer. **Download updated from library** (on the item menu, and in the designer or theme page) replaces that copy with the current library item so the company website shows the latest shared design. The name stays. The shared library is not changed. Create new makes an item for this website that is not copied from the library. Editing either one does not change the shared library, and later library edits do not change copies until you download the update.
6. Super Admin maintains that library under **Website** (Pages, Layouts, Headers, Footers, Presets, and Themes).

Pair pages with a [layout](/docs/website-forms/website-layouts), [headers and footers](/docs/website-forms/headers-footers), and a [theme](/docs/website-forms/website-themes). Reuse designed content elements with [website presets](/docs/website-forms/website-presets). Share the public address from [Public company site URL](/docs/website-forms/public-site-url).
