1. Open **Website → Pages**. Registering a company adds default pages, layouts, headers, footers, presets, datasets, and a theme. Edit or delete those starter items the same way as any other item. Delete is refused while another item still uses them. The default home page shows the company name, a short welcome line, and a Get in touch button.
2. Open an existing page, or choose **Add page**. Then pick **Add from library** to copy a shared page, or **Create new** to make one for this website. Choose a **layout** so the page uses that header, footer, and nav menu. Colors come from the **Active theme**. **Edit details** includes a color palette. Inherit uses the theme palette. A palette chosen here applies to content on that page that does not set its own. Super Admin uses **Add page** to add a library page directly.
3. Use the page designer to add content, then save. **Add block** adds a block. In the navigation tree, drag an item onto another block to move it there. Open a block or add-on settings and set **Name**. The same settings include a color palette. Inherit follows the parent block, page, header, footer, or preset. Choosing a palette applies it to children that inherit. The tree shows that name, with the element type on the line below. Hover a row in the navigation tree to highlight that element on the canvas. Selecting an element outlines its parent with a lighter dashed border. Grid lines appear while you drag or resize an element. The chat icon in the designer header opens the assistant. On a content-tree item, open the menu and choose **Copy to AI** to name that element in the assistant. Ask it to add a heading, button, image, menu, or slider. Confirm the suggestion to place it on the canvas, then **Save**. Ask the assistant to change an existing block, to move it left, center, or right, or to place it on the canvas grid and change its width or height. The element you name keeps that cell and size. Anything it would cover shifts to the next free cell. Confirm that edit the same way. Edits use the canvas as it is now, so changes you made by hand stay unless you asked to change that part. The assistant builds a larger section from small groups, and each group holds at least two related items. Each item is sized to its content, with no empty width or height. New sections stack full width. On a phone each item stacks; on a tablet narrow items sit side by side; on desktop buttons share a row. Switch the designer size control to check each width. Drag the strip under the canvas to set its height for the selected size. Phone, tablet, laptop, desktop, and wide each keep their own height.
4. Open the live site from the company profile **Website** URL, or use Preview / Browse in Website.
5. On Pages, Layouts, Headers, Footers, Presets, and Themes, **Add** asks whether to **Add from library** or **Create new**. Add from library copies a shared item into this website and keeps a link to that library item. The copy is marked **From library**. Company admins can edit it in the designer. **Download updated from library** (on the item menu, and in the designer or theme page) replaces that copy with the current library item so the company website shows the latest shared design. The name stays. The shared library is not changed. Create new makes an item for this website that is not copied from the library. Editing either one does not change the shared library, and later library edits do not change copies until you download the update.
6. Super Admin maintains that library under **Website** (Pages, Layouts, Headers, Footers, Presets, and Themes).

Pair pages with a [layout](/docs/website-forms/website-layouts), [headers and footers](/docs/website-forms/headers-footers), and a [theme](/docs/website-forms/website-themes). Reuse designed blocks with [website presets](/docs/website-forms/website-presets). Share the public address from [Public company site URL](/docs/website-forms/public-site-url).
