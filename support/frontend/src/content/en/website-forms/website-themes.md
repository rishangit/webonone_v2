1. Open Design website **themes**.
2. Create a theme: give it a name and set **1 to 7** palette colors (Primary, Secondary, Background, Surface, Text, then Color 6 and Color 7). Add or remove colors in the dialog. At least one color is required.
3. Optional: on [CColorPalette](https://ccolorpalette.com/), choose a palette of 1–7 colors → **Export** → **CSS variables**, then **Paste CSS from CColorPalette** to fill the palette.
4. Open the theme to rename colors, add more colors, and edit fonts, text styles, and buttons. The Colors tab can import a palette again; extra colors stay, and renamed role names are kept.
5. Save. On each **layout**, pick which theme those pages use. If a layout has no theme, the company default theme is used.

See [Website layouts](/docs/website-forms/website-layouts). Media for the site is managed under website media in Design.
