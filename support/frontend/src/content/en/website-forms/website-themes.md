title: "Website themes and design tokens"
category: website-forms
slug: website-themes
audience: owner
order: 8
summary: "Add a website theme by name, then edit basic settings, fonts, color palettes, texts, and buttons on the theme page. Pick that theme on a layout."
---

1. Open **Website → Themes**.
2. Choose **Add theme**, then **Add from library** to copy a shared theme, or **Create new** and enter a name. A library copy is marked **From library**. The theme that applies on the site is marked **Active theme**. On another theme, choose **Set as active theme** to make that one the theme in effect. Company admins can edit it. **Download updated from library** on the theme page replaces colors, fonts, and styles with the current library theme so the company website uses that update. The name stays. This is the website theme, separate from Settings themes. Super Admin uses **Add theme** to add a library theme directly.
3. The theme detail page opens with **Basic settings**, **Fonts**, **Color palettes**, **Texts**, and **Buttons**.
4. On **Basic settings**, set the name. Pick the theme **color palette**. That palette is the one pages, headers, footers, presets, text styles, button styles, and page elements inherit unless they choose their own. **Page background** (main website background), **Surface color** (cards, content panels, form backgrounds), **Main text color** (headings and body defaults), **Accent color 1**, and **Accent color 2** (highlights, badges, emphasized elements) each have a **color palette** and a **color**. **Inherit** on a color’s palette uses the theme palette, including a later change to that palette. Choose any other palette on the theme when that color should come from it. **None** at the top of each color list leaves that color unset. The theme palette list also starts with **None**. Add palettes first on the **Color palettes** tab.
5. On **Fonts**, choose **Add font**. The dialog asks **From library** or **Custom**. Pick one, then **Next**. **From library** lists shared fonts. **Custom** asks for a Google Font URL. **Previous** returns to that question. The name, URL, and font family are saved on the theme. Super Admin sees a note on the custom form: a custom font they add is also saved to that shared library for every company website. Super Admin can also manage the full library under **Website** → **Fonts** — see [Website font library](website-font-library.md).
6. On **Color palettes**, choose **Add color palette**. Use **From library** or **Custom** (same flow as fonts). Optional: on [CColorPalette](https://ccolorpalette.com/), choose a palette → **Export** → **CSS variables**, then **Paste CSS from CColorPalette**. Super Admin manages the shared library under **Website** → **Colors** — see [Website color library](website-color-library.md).
7. On **Texts** and **Buttons**, add styles that use those fonts and colors. Text and button basic settings include **Inherit** on the color palette. Inherit uses the palette selected for the theme, including a later change to that palette. Choose another palette on the style when it should keep its own. Text then picks a **font color** from the effective palette. **None** leaves the font color, and a button’s background, text, or border color, unset — the same controls as [library texts](/docs/website-forms/website-text-library). Text and button settings on a page list the styles from the theme marked **Active theme**, not from another theme. A text or button element stores the position of the chosen style in that list. Changing the active theme uses the style in the same position. Super Admin can also manage the shared libraries under **Website** → **Texts** and **Website** → **Buttons**, including [Copy to AI](/docs/website-forms/website-button-library) to redesign HTML, styles, and script.
8. Open a theme **button** or **text** from those lists. If it was added **From library**, company admins choose **Download updated from library** to replace that copy with the current shared style so the company website uses it. Your edits on that copy are lost. The shared library is not changed. Button and text details stay view-only: hover a card and choose Edit to open the add/edit dialog on that tab. Library buttons, library copies on a theme, and **Custom** theme buttons use the same Basic settings: style name, font type, color palette, background, text color, border color, text size, border width, and radius.
9. The designer and the live site use the theme marked **Active theme** for colors, text styles, and button styles. A layout still supplies the header, footer, and menu.

See [Website layouts](/docs/website-forms/website-layouts). Media for the site is managed under **Website → Media**.
