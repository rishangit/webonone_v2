summary: "Create named header, footer, and theme shells and assign pages so Home and About can share one layout while Help uses another."
---

1. Open **Design → Website → Layouts**.
2. Add a layout. Give it a name, pick a **header**, **footer**, and **theme**, and optionally mark it as the default.
3. On each **page**, choose that layout (Home and About can share Main; Help can use a different layout).
4. On the layout, use **Menu order** to set the order of links in the header nav.

The live site wraps each page with that layout’s header, footer, and theme. Pages on the same layout share chrome, look, and the same nav menu.

Pair this with [Headers and footers](/docs/website-forms/headers-footers), [Website themes](/docs/website-forms/website-themes), and [Header menu](/docs/website-forms/header-menu). Create pages under [Website pages](/docs/website-forms/website-pages).
