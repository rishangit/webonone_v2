1. Open **Website → Headers** or **Website → Footers**.
2. Edit the chrome (logo, Nav menu, and blocks) in the designer. Choose **Add header** or **Add footer**, then **Add from library** or **Create new**. **Edit details** sets the color palette for that header or footer. Inherit uses the theme palette, and a chosen palette applies to content that does not set its own. Super Admin uses those Add buttons to add a library header or footer directly.
3. Save. A **layout** picks which header and footer wrap each page.

Add a **Nav menu** add-on on the header so layout pages appear as links. On phones that menu becomes a hamburger. See [Header menu](/docs/website-forms/header-menu) and [Website layouts](/docs/website-forms/website-layouts).

**Add from library** copies a shared header or footer into this website and keeps a link to the library item. The copy is marked **From library**. Company admins can edit it. **Download updated from library** replaces that copy with the current library item so the company website uses it. **Create new** starts one for this website. Editing either one does not change the library. Super Admin maintains those library items under **Website**.

Super Admin adds shared images under **Website → Media**. That page is the media list. The toolbar has search, upload, and the list and card view buttons. New folder opens in a dialog over the page. Those files stay in the website library and are served by their public URL. When a company uses a library header or footer that includes those images, the company designer and the live site show the images from that URL. Drag a file or a folder onto another folder to move it there. The breadcrumb is a drop target too, so an item can move up to a parent folder.
