summary: "Edit site chrome in the header and footer designers, then pick them on a layout."
---

1. Open **Website → Headers** or **Website → Footers**.
2. Edit the chrome (logo, Nav menu, and blocks) in the designer. Company admins add a header or footer with **Duplicate** or **Add from library**. The blank **Add header** / **Add footer** button is only for Super Admin.
3. Save. A **layout** picks which header and footer wrap each page.

Add a **Nav menu** add-on on the header so layout pages appear as links. On phones that menu becomes a hamburger. See [Header menu](/docs/website-forms/header-menu) and [Website layouts](/docs/website-forms/website-layouts).

**Add from library** copies a shared header or footer into this website. Editing the copy does not change the library. Super Admin maintains those library items under **Website**.
