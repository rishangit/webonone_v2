---
title: "Create and edit tags"
category: catalog
slug: tags
audience: owner
order: 2
summary: "Add tags under Data → Tags. They stay unverified until a Super Admin verifies them."
---

1. Open **Data → Tags**.
2. Choose **Add**, name the tag, and save.
3. Edit or delete from the row menu when allowed.

Use tags on company profile and catalog items. Super Admins verify platform library tags — see [unverified items](/docs/catalog/unverified-items).
