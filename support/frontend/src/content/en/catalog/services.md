1. Open **Data → Services**.
2. Add a service and set **time mode** (window vs duration) and any **spaces**.
3. Save. Calendar [events](/docs/calendar/create-event) pick from these services.
4. Open the company service and choose **Attributes → Add attribute**. **Add** on a library-service row copies that attribute onto the company service. **Add new attribute** lists Data library attributes and attaches them to the linked library service; copy them onto the company service afterward if you want. On the attribute page, **Add value** copies existing library values, and **Create value** writes a new value in the library and links it to the company service.

Details pages show reference counts (how many events or items use the service). Adding a service from the library keeps the link to that Data library service. Open the **⋮** menu and choose **Edit** (or use **Edit** on a section card) to change name, time, tags, and more; the wizard shows library values and marks fields you change as **Edited**.

Company admins set selling prices on the service **Prices & discounts** tab. The **Prices** card lists amounts: add a price, then set one as the active price. The **Discounts** card lists percentage discounts taken off that active price. Each discount can apply **All time**, on **Selected days**, or across a **Selected range** (start date and end date), and to **Everyone** or **Selected users**. **Select user** opens the user picker. The services list and Overview show the active price after the discount that matches today and the person viewing the service.
