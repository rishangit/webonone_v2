1. Open **Data → Services**.
2. Add a service and set **time mode** (window vs duration) and any **spaces**.
3. Save. Calendar [events](/docs/calendar/create-event) pick from these services.
4. Open the company service and choose **Attributes → Add attribute**. **Add** on a library-service row copies that attribute onto the company service. **Add new attribute** lists Data library attributes and attaches them to the linked library service; copy them onto the company service afterward if you want. On the attribute page, **Add value** copies existing library values, and **Create value** writes a new value in the library and links it to the company service.

Details pages show reference counts (how many events or items use the service). Adding a service from the library keeps the link to that Data library service.

Company admins set selling prices on the service **Price list** tab. Add a price, then choose **All time** or **Selected days**. For selected days, pick the weekdays and either **Full day** or **Specific time** with a start and end. Then choose **Everyone** or **Selected users**. The services list and Overview show the price that matches the current day, time, and the person viewing the service.
