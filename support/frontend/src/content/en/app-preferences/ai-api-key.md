---
title: "Configure your AI API key"
category: app-preferences
slug: ai-api-key
audience: all
order: 7
summary: "Add your Ollama Cloud or OpenAI key in Basic Settings → AI."
---

1. Open **Settings → Basic Settings**.
2. Open the **AI** card.
3. Choose a **provider** (Ollama or OpenAI), paste your API key, set the model and base URL if needed, and save.

Without a key, the in-app assistant cannot call the model, and text fields do not show the [writing sparkle](/docs/app-preferences/field-ai-polish). Keys are stored for your user — they are not shown on this public help site.

Super Admins can also configure the **website guest assistant** on the platform AI card in the same settings area.
