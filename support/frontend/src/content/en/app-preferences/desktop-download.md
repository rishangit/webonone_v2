summary: "Get the Windows installer from Basic Settings → Downloads."
---

1. Open **Settings → Basic Settings**.
2. Open the **Downloads** tab.
3. Choose **Download for Windows** to save `WebOnOne-Setup.exe`.
4. Run the installer, then open **WebOnOne** from the Start menu and sign in.

The desktop app uses the same features as the browser. See [Use the desktop app](/docs/getting-started/desktop-app) for more detail.
