---
title: "Reset your password"
category: getting-started
slug: reset-password
audience: all
order: 7
summary: "Use Forgot password, enter the OTP sent to you, then set a new password."
---

1. On the sign-in screen, choose **Forgot password**.
2. Enter the email (or phone, if offered) for your account.
3. Open the one-time code (OTP) you receive by email or SMS.
4. Enter the code, then set a **new password**.
5. Sign in with the new password.

If the code expires, request a new one from the same screen. For SMS delivery issues, the company SMS gateway must be online — see [Troubleshooting: SMS gateway](/docs/glossary/troubleshooting-gateway).
