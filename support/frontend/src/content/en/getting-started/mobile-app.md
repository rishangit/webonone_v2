---

1. Install the **WebOnOne** mobile app.
2. Sign in with the same email you use on the web.
3. [Choose the account](/docs/getting-started/choose-account) if you have more than one (Super Admin, company owner, staff, or default user).
4. Open the **menu** (top left) for the same left navigation as the web app. Only items for your current account appear.
5. Open your name in the header for **Profile**. Switch accounts from the bottom of the menu when you have more than one.

Company owners and Super Admins also see **SMS**. To send messages from this phone’s SIM, follow [Install the mobile app as an SMS gateway](/docs/communications/mobile-gateway).

**Analytics**, Calendar, Sales, Data, Email, Payment, and Profile are native screens (same data as the web app). **Design** still opens the web page inside the app or in the browser.
