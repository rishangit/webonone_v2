1. Open the running **window-mode** session.
2. Choose **Issue token** (or the equivalent action on the session screen).
3. Identify the customer if asked, then confirm.

The token appears in the queue. Use call next/previous to serve people in call order. See the [glossary](/docs/glossary/glossary) for “token”.

## Late check-in

If a customer’s number was already passed (a higher number is serving or completed) and they check in late, they **keep the same token number** on screen. The system only adjusts **call order** so projected waiting time stays roughly equal for everyone already checked in. A late arriver may be called before someone who checked in earlier if that person has already waited longer.
