1. **Settings → Basic Settings** විවෘත කරන්න.
2. **AI** card විවෘත කරන්න.
3. ඔබේ provider API key අලවා, ලැයිස්තුගත නම් model එකක් තෝරා, සුරකින්න.

key එකක් නොමැතිව, යෙදුම තුළ සහායකයට model එක call කළ නොහැක. keys ඔබේ user සඳහා ගබඩා කෙරේ — මෙම public help site හි ඒවා පෙන්වන්නේ නැත.

Super Admins එකම settings ප්‍රදේශයේ platform AI card හි **website guest assistant** ද සකස් කළ හැක.
