summary: "Basic Settings → Downloads හි Windows installer ලබා ගන්න."
---

1. **Settings → Basic Settings** විවෘත කරන්න.
2. **Downloads** tab විවෘත කරන්න.
3. `WebOnOne-Setup.exe` සුරැකීමට **Windows සඳහා download** තෝරන්න.
4. Installer ධාවනය කර Start menu හි **WebOnOne** විවෘත කර sign in වන්න.

Desktop app browser එකේ features භාවිතා කරයි. වැඩි විස්තර සඳහා [Desktop app භාවිතා කරන්න](/docs/getting-started/desktop-app) බලන්න.
