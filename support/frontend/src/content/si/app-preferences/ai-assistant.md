ඔබ sign in වී සිටින විට, header හි **chat** බොත්තමක් දිස්වේ.

1. සහායක panel විවෘත කිරීමට එය click කරන්න.
2. සරල භාෂාවෙන් අසන්න (උදාහරණයක් ලෙස, සැකසුමක් සොයා ගැනීමට උදව්).
3. සහායකයට යමක් සාදන්න හෝ වෙනස් කරන්න අවශ්‍ය නම්, ඉල්ලූ විට ක්‍රියාව තහවුරු කරන්න.

සහායකයට ක්‍රියාත්මක API key එකක් අවශ්‍යයි. [AI API key](/docs/app-preferences/ai-api-key) යටතේ එය සකස් කරන්න. public website හි guests වෙනම [catalog assistant](/docs/public-catalog/guest-assistant) භාවිතා කරයි.
