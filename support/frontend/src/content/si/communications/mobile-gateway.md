1. **WebOnOne** mobile app ස්ථාපනය කරන්න (Android gateway device SIM භාවිතා කරයි).
2. web හි භාවිතා කරන එකම ගිණුමෙන් sign in වන්න.
3. [සමාගම් ගිණුම තෝරන්න](/docs/getting-started/choose-account).
4. gateway home විවෘත කර මෙම දුරකථනය ලියාපදිංචි කරන්න.
5. web හි, ඉල්ලූ විට [device අනුමත කරන්න](/docs/communications/sms-devices).

SMS යැවීම අපේක්ෂා කරන විට app ධාවනය වන අතර දුරකථනය online තබා ගන්න.
