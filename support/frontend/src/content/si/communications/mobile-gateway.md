1. **WebOnOne** mobile app ස්ථාපනය කරන්න (Android gateway device SIM භාවිතා කරයි). [WebOnOne mobile app භාවිතා කරන්න](/docs/getting-started/mobile-app) බලන්න.
2. web හි භාවිතා කරන එකම ගිණුමෙන් sign in වන්න.
3. [සමාගම් ගිණුම තෝරන්න](/docs/getting-started/choose-account) (Super Admin හෝ company owner — members ට SMS නොපෙනේ).
4. Left menu → **SMS** → **This device** විවෘත කර මෙම දුරකථනය ලියාපදිංචි කරන්න.
5. web හි හෝ app හි, ඉල්ලූ විට [device අනුමත කරන්න](/docs/communications/sms-devices).

SMS යැවීම අපේක්ෂා කරන විට app ධාවනය වන අතර දුරකථනය online තබා ගන්න.
