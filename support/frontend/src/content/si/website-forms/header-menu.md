---

1. නිර්මාණකරුවේ **header** එකක් විවෘත කරන්න.
2. content element එකක් එක් කර, පසුව **Nav menu** add-on එක එක් කරන්න (ශීර්ෂ පමණි).
3. සබැඳි තිබිය යුතු තැනට තබන්න (සාමාන්‍යයෙන් ලාංඡනය අසල). අවශ්‍ය නම් පෙළ විලාසයක් සහ පෙළගැස්ම තෝරන්න.
4. මෙම ශීර්ෂය භාවිතා කරන layout එකට පිටු යොදන්න. ඒ **සක්‍රීය** පිටු මෙනුව වේ, layout මෙනු අනුපිළිවෙලින්.

**පුළුල් තිර** මත add-on එක පිටු නම් පේළියක් පෙන්වයි. **දුරකථන** (`sm` canvas) මත එම add-on **මෙනු** අයිකනයක් පෙන්වයි. එය තට්ටු කර දකුණෙන් පැනලයක් ලබා ගන්න. පිටුවකට යාමට තට්ටු කරන්න; පිටත, **X**, හෝ Escape මගින් වසන්න.

ප්‍රධාන nav සඳහා Button add-on භාවිතා නොකරන්න. බොත්තම් CTA සඳහා වන අතර ජංගමවේදී හකුළන්නේ නැත.
