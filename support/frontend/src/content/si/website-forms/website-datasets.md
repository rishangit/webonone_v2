1. **Design → Website** විවෘත කර **දත්ත කට්ටල** ටැබය තෝරන්න.
2. **දත්ත කට්ටලයක් එක් කරන්න** ක්ලික් කර නමක් දී **මූලාශ්‍ර වර්ගය** තෝරන්න (නිෂ්පාදන, සේවා, අවකාශ, කාර්ය මණ්ඩල, පරිශීලකයින් හෝ විශ්ලේෂණ).
3. විශ්ලේෂණ සඳහා **මානයක්** සහ අවශ්‍ය නම් දින පරාසයක් තෝරන්න.
4. **පෙරහන්** පියවරේදී තත්ත්වය සක්‍රිය හෝ මිල 200 ට වඩා වැඩි වැනි රීති එක් කරන්න.
5. දත්ත කට්ටලය සුරකින්න. පෙරහන් සුරැකෙයි — වෙබ් අඩවිය සෑම විටම **සජීවී** පේළි කියවයි.
6. පොදු API එකට දත්ත ලබා දීමට තත්ත්වය **සක්‍රිය** කරන්න.

සක්‍රිය දත්ත කට්ටලයක් හරහා නිරාවරණය වන දත්ත පමණක් සමාගම් වෙබ් අඩවියේ පෙන්විය යුතුය.
