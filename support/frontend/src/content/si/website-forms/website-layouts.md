1. **Website → Layouts** විවෘත කරන්න.
2. **පිරිසැලසුමක් එක් කරන්න** තෝරන්න. ඉන්පසු **පුස්තකාලයෙන් එක් කරන්න** මගින් බෙදාගත් layout එකක් පිටපත් කරන්න, නැතහොත් **අලුතින් සාදන්න** මගින් මෙම වෙබ් අඩවිය සඳහා එකක් සාදන්න. නමක් දී **header**, **footer** සහ **theme** තෝරන්න, අවශ්‍ය නම් පෙරනිමිය ලෙස සලකුණු කරන්න. Super Admin **පිරිසැලසුමක් එක් කරන්න** මගින් පුස්තකාල layout එකක් සෘජුව එක් කරයි.
3. එක් එක් **page** මත එම layout එක තෝරන්න (Home සහ About Main බෙදා ගත හැකි අතර Help වෙනත් එකක් භාවිතා කරයි).
4. Layout එකේ **Menu order** භාවිතා කර ශීර්ෂ මෙනුවේ සබැඳි අනුපිළිවෙල සකසන්න.

සජීවී අඩවිය එක් එක් පිටුව එම layout එකේ ශීර්ෂයෙන්, පාදමෙන් සහ තේමාවෙන් ඔතයි. එකම layout එකේ පිටු එකම chrome, පෙනුම සහ මෙනුව බෙදා ගනී.

**පුස්තකාලයෙන් එක් කරන්න** මගින් බෙදාගත් layout එකක්, එහි ශීර්ෂය, පාදම සහ තේමාව සමඟ, මෙම වෙබ් අඩවියට පිටපත් වේ, සහ පුස්තකාල layout එකට සබැඳියක් තබයි. පිටපත **පුස්තකාලයෙන්** ලෙස සලකුණු වේ. සමාගම් පරිපාලකයින්ට එය වෙනස් කළ හැක. **පුස්තකාලයෙන් යාවත්කාලීනය බාගන්න** layout එක නැවත පුස්තකාල ශීර්ෂය, පාදම සහ තේමාවට යොමු කර, ඒවායේ පිටපත් වත්මන් පුස්තකාල අනුවාදයෙන් ප්‍රතිස්ථාපනය කරයි, එවිට සමාගම් වෙබ් අඩවිය ඒවා භාවිතා කරයි. **අලුතින් සාදන්න** මගින් මෙම වෙබ් අඩවියට අයත් layout එකක් ආරම්භ වේ. දෙකම සංස්කරණය කිරීම පුස්තකාලය වෙනස් නොකරයි. Super Admin **Website** යටතේ පුස්තකාල layouts පවත්වාගෙන යයි.
