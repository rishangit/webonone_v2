Super Admin සෑම සමාගම් වෙබ් අඩවියකටම බෙදාගත් **අකුරු පුස්තකාලය** පරිපාලනය කරයි.

## අකුරු පුස්තකාලය විවෘත කිරීම

1. Super Admin ලෙස **Design** වෙත පිවිසෙන්න.
2. වම් මෙනුවෙන් **Website** → **Fonts** විවෘත කරන්න.

## ලැයිස්තුව සහ සෙවීම

සක්‍රිය අකුරු පෙරදසුන සමඟ ලැයිස්තුගත වේ. නම හෝ font family අනුව සෙවීමට සෙවුම් කොටුව භාවිතා කරන්න.

## අකුරු එක් කිරීම

1. **Add font** ඔබන්න.
2. **Style name** ඇතුළත් කරන්න.
3. [Google Fonts](https://fonts.google.com/) වෙතින් **Google Font stylesheet URL** හෝ `<link>` tag අලවන්න.
4. **Font family** හඳුනාගෙන ඇති බව තහවුරු කර **Save** ඔබන්න.

සමාගම් පරිපාලකයින් තේමාවකට අකුරු එක් කරන විට **From library** තෝරන විට අකුරු වහාම ලබා ගත හැක.

## අකුරු ඉවත් කිරීම

1. අකුරු පේළියේ තුන ලක්ෂණ මෙනුව විවෘත කරන්න.
2. **Delete** තෝරා තහවුරු කරන්න.

ඉවත් කිරීමෙන් පුස්තකාල තෝරකයෙන් අකුරු සැඟවේ. දැනටමත් භාවිතා කරන තේමා වෙනස් නොවේ.
