Super Admin **බෙදාගත් වර්ණ පුස්තකාලය** පරිපාලනය කරයි. සමාගම් පරිපාලකයින් තේමාවකට වර්ණ එක් කරන විට එය භාවිතා කරයි.

## Super Admin: පුස්තකාලය

1. Super Admin ලෙස පිවිසෙන්න.
2. **Website** → **Colors** විවෘත කරන්න.
3. සොයන්න, **Add color**, හෝ පුස්තකාලයෙන් මකන්න.

## සමාගම් පරිපාලක: තේමාවට වර්ණ

1. **Website** → **Themes** → තේමාව → **Colors**.
2. **Add color** තෝරන්න.
3. **From library** — බෙදාගත් වර්ණය තේමාවට පිටපත් කරයි. **Custom** — මෙම තේමාවට පමණක් වර්ණය සාදයි.

Super Admin අභිරුචි වර්ණ ද බෙදාගත් පුස්තකාලයට සුරැකේ.

[Website themes](website-themes.md) බලන්න.
