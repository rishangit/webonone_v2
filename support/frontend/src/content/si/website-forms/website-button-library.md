Super Admin **බෙදාගත් button library** කළමනාකරණය කරයි. Company admins තේමාවකට buttons එක් කරන විට මෙයින් තෝරයි.

## Button විලාසයක් විවෘත කරන්න

1. Super Admin ලෙස පිවිසෙන්න.
2. **Website** → **Buttons** විවෘත කරන්න.
3. පේළියක් ක්ලික් කරන්න, නැතහොත් three-dot menu → **Edit** තෝරන්න.

විස්තර පිටුවේ **Preview**, **Basic settings**, **HTML**, **Styles**, සහ **Scripts** ඇත. එම tabs වෙනස් වන විට preview යාවත්කාලීන වේ.

## Button සංස්කරණය

1. විස්තර පිටුවේ කොටස් කාඩ් එකක් (**Preview**, **Basic settings**, **HTML**, **Styles**, හෝ **Scripts**) මත hover කර Edit අයිකනය ක්ලික් කරන්න.
2. **පුස්තකාලයට බොත්තම් විලාසය එක් කරන්න** dialog එක එම tab එකෙන් විවෘත වේ.
3. ක්ෂේත්‍ර වෙනස් කර **Save** කරන්න. විස්තර පිටුව view ලෙසම පවතී.

HTML තුළ `{{label}}` තබන්න — සමාගම් වෙබ් අඩවි button පෙළ පුරවයි. Root මූලද්‍රව්‍යය `<button>` විය යුතුය (`div` wrapper නොවේ). මූලික සැකසුම් එම බොත්තමට යෙදේ. Styles tab එකේ එම බොත්තමේ `.website-el-…` පන්තිය ඇත.

## Copy to AI

Design, WebOnOne තුළ විවෘතව ඇති විට:

1. Button විස්තර පිටුවේ (හෝ ලැයිස්තු පේළියේ) three-dot menu විවෘත කරන්න.
2. **Copy to AI** තෝරන්න. එම button සහායකයට attach වේ.
3. සාමාන්‍ය භාෂාවෙන් විලාස වෙනසක් ඉල්ලන්න.
4. යෝජනාව සමාලෝචනය කර **Confirm** තෝරන්න. සහායකය වෙනස් කරන්නේ basic settings, HTML, styles, සහ script පමණි.
5. පිටුවේම රැඳී සිටින්න — confirm කළ පසු preview නැවත පූරණය වේ.

තවත් බලන්න: [AI assistant capabilities](/docs/app-preferences/ai-assistant) සහ [Website themes](/docs/website-forms/website-themes).
