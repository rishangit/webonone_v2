1. Design website **themes** විවෘත කරන්න.
2. තේමාවක් සාදන්න: නමක් දී **වර්ණ 1 සිට 7 දක්වා** සකසන්න (Primary, Secondary, Background, Surface, Text, ඉන්පසු Color 6 සහ Color 7). දෙබසෙහි වර්ණ එක් කරන්න හෝ ඉවත් කරන්න. අවම වශයෙන් එක් වර්ණයක් අවශ්‍යයි.
3. විකල්පය: [CColorPalette](https://ccolorpalette.com/) හි වර්ණ 1–7ක පැලටයක් තෝරන්න → **Export** → **CSS variables**, පසුව පැලටය පිරවීමට **Paste CSS from CColorPalette** භාවිතා කරන්න.
4. තේමාව විවෘත කර වර්ණ නැවත නම් කරන්න, තවත් වර්ණ එක් කරන්න, fonts, text styles සහ buttons සංස්කරණය කරන්න. Colors ටැබයෙන් නැවත පැලටයක් ආයාත කළ හැක; අමතර වර්ණ ඉතිරි වන අතර නැවත නම් කළ භූමිකා නම් රැඳේ.
5. සුරකින්න. එක් එක් **layout** මත එම පිටු භාවිතා කරන තේමාව තෝරන්න. Layout එකක තේමාවක් නැත්නම් සමාගම් පෙරනිමි තේමාව භාවිතා වේ.

[Website layouts](/docs/website-forms/website-layouts) බලන්න. Site media Design හි website media යටතේ කළමනාකරණය වේ.
