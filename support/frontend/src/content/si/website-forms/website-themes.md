1. **Website → Themes** විවෘත කරන්න.
2. **තේමාවක් එක් කරන්න** තෝරන්න. ඉන්පසු **පුස්තකාලයෙන් එක් කරන්න** මගින් බෙදාගත් තේමාවක් පිටපත් කරන්න, නැතහොත් **අලුතින් සාදන්න** තෝරා නමක් දෙන්න. පුස්තකාල පිටපත **පුස්තකාලයෙන්** ලෙස සලකුණු වේ. වෙබ් අඩවියට බලපාන තේමාව **සක්‍රීය තේමාව** ලෙස සලකුණු වේ. වෙනත් තේමාවක් මත **සක්‍රීය තේමාව ලෙස සකසන්න** තෝරා එය බලපාන තේමාව කරන්න. සමාගම් පරිපාලකයින්ට එය සංස්කරණය කළ හැක. තේමා පිටුවේ **පුස්තකාලයෙන් යාවත්කාලීනය බාගන්න** වර්ණ, අකුරු, සහ රටා වත්මන් පුස්තකාල තේමාවෙන් ප්‍රතිස්ථාපනය කරයි, එවිට සමාගම් වෙබ් අඩවිය එම යාවත්කාලීනය භාවිතා කරයි. නම එලෙසම පවතී. මෙය Settings තේමාවලින් වෙනම website තේමාවකි. Super Admin **තේමාවක් එක් කරන්න** මගින් පුස්තකාල තේමාවක් සෘජුව එක් කරයි.
3. තේමා විස්තර පිටුව විවෘත වේ. එහි **මූලික සැකසුම්**, **අකුරු**, **වර්ණ පැලට්**, **පෙළ**, සහ **බොත්තම්** ඇත.
4. **මූලික සැකසුම්** යටතේ නම සකසන්න. තේමා **වර්ණ පැලට්** එක තෝරන්න. පිටු, ශීර්ෂ, පාදම්, presets, පෙළ විලාස, බොත්තම් විලාස, සහ පිටු මූලාංග තමන්ගේ පැලටයක් තෝරා නොගන්නේ නම් මෙම පැලටය උරුම කරගනී. ඉන්පසු එම පැලට් එකෙන් **පිටු පසුබිම** (ප්‍රධාන වෙබ් අඩවි පසුබිම), **පෘෂ්ඨ වර්ණය** (කාඩ්, අන්තර්ගත පැනල, පෝරම පසුබිම්), **ප්‍රධාන පෙළ වර්ණය** (ශීර්ෂ සහ බොඩි පෙරනිමි), **උද්දීපන වර්ණය 1**, සහ **උද්දීපන වර්ණය 2** (උද්දීපන, ලාංඡන) තෝරන්න. පැලට් **වර්ණ පැලට්** ටැබයේ පළමුව එක් කරන්න.
5. **අකුරු** යටතේ **Add font** තෝරන්න. සංවාදය **පුස්තකාලයෙන්** හෝ **අභිරුචි** යනුවෙන් අසයි. එකක් තෝරා **Next** ඔබන්න. **පුස්තකාලයෙන්** බෙදාගත් අකුරු ලැයිස්තුවයි. **අභිරුචි** Google Font URL එකක් ඉල්ලයි. **Previous** නැවත එම ප්‍රශ්නයට ගෙන යයි. නම, URL, සහ font family තේමාවේ සුරැකේ. Super Admin අභිරුචි පෝරමයේ සටහනක් දකී: ඔවුන් එක් කරන අභිරුචි අකුරු බෙදාගත් පුස්තකාලයට ද සුරැකේ. Super Admin **Website** → **Fonts** මගින් පුර්ණ පුස්තකාලය ද කළමනාකරණය කළ හැක — [Website font library](website-font-library.md) බලන්න.
6. **වර්ණ පැලට්** යටතේ වර්ණ පැලට් එකක් එක් කරන්න. විකල්පය: [CColorPalette](https://ccolorpalette.com/) හි පැලටයක් තෝරන්න → **Export** → **CSS variables**, පසුව **Paste CSS from CColorPalette** භාවිතා කරන්න.
7. **පෙළ** සහ **බොත්තම්** යටතේ එම අකුරු සහ වර්ණ භාවිතා කරන විලාස එක් කරන්න. පෙළ සහ බොත්තම් මූලික සැකසුම්වල වර්ණ පැලටයේ **උරුම කරගන්න** ඇත. උරුමය තේමාවට තෝරා ඇති පැලටය භාවිතා කරයි, එම පැලටය පසුව වෙනස් වුවද. විලාසයට තමන්ගේ පැලටයක් තබා ගැනීමට වෙනත් පැලටයක් තෝරන්න. පෙළ ඉන්පසු එම පැලට් එකෙන් **අකුරු වර්ණය** තෝරයි — [පුස්තකාල පෙළ](/docs/website-forms/website-text-library) සමඟ එකම පාලන. පිටුවේ පෙළ සහ බොත්තම් සැකසුම් **සක්‍රිය තේමාව** ලෙස සලකුණු කළ තේමාවේ විලාස ලැයිස්තුගත කරයි. වෙනත් තේමාවක විලාස නොපෙන්වයි. පෙළ හෝ බොත්තම් මූලාංගයක් තෝරාගත් විලාසයේ ස්ථානය සුරකියි. සක්‍රිය තේමාව වෙනස් කළ විට එම ස්ථානයේ විලාසය භාවිතා වේ. Super Admin **Website** → **Texts** සහ **Website** → **Buttons** යටතේ බෙදාගත් libraries ද කළමනාකරණය කළ හැක, [Copy to AI](/docs/website-forms/website-button-library) ඇතුළුව.
8. ඒ ලැයිස්තුවලින් තේමා **බොත්තමක්** හෝ **පෙළක්** විවෘත කරන්න. එය **පුස්තකාලයෙන්** එක් කළේ නම්, සමාගම් පරිපාලකයින් **පුස්තකාලයෙන් යාවත්කාලීනය බාගන්න** තෝරා වත්මන් බෙදාගත් විලාසයෙන් ප්‍රතිස්ථාපනය කරයි, එවිට සමාගම් වෙබ් අඩවිය එය භාවිතා කරයි. මෙම පිටපතේ වෙනස්කම් නැති වේ. බෙදාගත් පුස්තකාලය වෙනස් නොවේ. බොත්තම් සහ පෙළ විස්තර පිටු view ලෙසම පවතී: කාඩ් එකක් මත hover කර Edit තෝරන්න — add/edit dialog එක එම tab එකෙන් විවෘත වේ. පුස්තකාල බොත්තම්, තේමාවේ පුස්තකාල පිටපත්, සහ **අභිරුචි** තේමා බොත්තම් එකම මූලික සැකසුම් භාවිතා කරයි: විලාස නම, අකුරු වර්ගය, වර්ණ පැලට්, පසුබිම, පෙළ වර්ණය, දාර වර්ණය, පෙළ ප්‍රමාණය, දාර පළල, සහ අරය.
9. නිර්මාණකරු සහ සජීවී අඩවිය වර්ණ, පෙළ විලාස, සහ බොත්තම් විලාස සඳහා **සක්‍රීය තේමාව** භාවිතා කරයි. Layout එක ශීර්ෂය, පාදම, සහ මෙනුව සපයයි.
