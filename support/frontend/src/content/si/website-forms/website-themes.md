1. **Website** විවෘත කර **themes** තෝරන්න.
2. **තේමාවක් එක් කරන්න** තෝරා නමක් දෙන්න. මෙය Settings තේමාවලින් වෙනම website තේමාවකි.
3. තේමා විස්තර පිටුව විවෘත වේ. එහි **මූලික සැකසුම්**, **අකුරු**, **වර්ණ**, **පෙළ**, සහ **බොත්තම්** ඇත.
4. **මූලික සැකසුම්** යටතේ නම, පිටු පසුබිම, සහ body text වර්ණය සකසන්න.
5. **අකුරු** යටතේ **Add font** තෝරන්න. **පුස්තකාලයෙන්** බෙදාගත් අකුරක් තෝරන්න, නැතහොත් **අභිරුචි** යටතේ Google Font URL එකක් ඇතුළත් කරන්න. නම, URL, සහ font family තේමාවේ සුරැකේ. Super Admin **පුස්තකාලයෙන්** යටතේ සටහනක් දකී: ඔවුන් එක් කරන අභිරුචි අකුරක් සෑම සමාගම් වෙබ් අඩවියකටම එම බෙදාගත් පුස්තකාලයට ද සුරැකේ.
6. **වර්ණ** යටතේ වර්ණ එක් කරන්න. විකල්පය: [CColorPalette](https://ccolorpalette.com/) හි පැලටයක් තෝරන්න → **Export** → **CSS variables**, පසුව **Paste CSS from CColorPalette** භාවිතා කරන්න.
7. **පෙළ** සහ **බොත්තම්** යටතේ එම අකුරු සහ වර්ණ භාවිතා කරන විලාස එක් කරන්න.
8. එක් එක් **layout** මත එම පිටු භාවිතා කරන තේමාව තෝරන්න. Layout එකක තේමාවක් නැත්නම් සමාගම් පෙරනිමි තේමාව භාවිතා වේ.

[Website layouts](/docs/website-forms/website-layouts) බලන්න. Site media **Website → Media** යටතේ කළමනාකරණය වේ.
