1. **Data → Attributes** විවෘත කරන්න.
2. ගුණාංගයක් එකතු කර, මන කළ හැකි නම් ඒකකයක් සම්බන්ධ කරන්න.
3. නිෂ්පාදන සහ සේවා wizard වල ගුණාංග භාවිතා කරන්න, එවිට variants සහ filters ස්ථිරව පවතී.
4. සමාගම් නිෂ්පාදනය, සේවාව, හෝ අවකාශය මත **Attributes** විවෘත කර **Add attribute** තෝරන්න. පුස්තකාල අයිතම පේළියක **Add** එම ගුණාංගය සමාගම් අයිතමයට පිටපත් කරයි. **Add new attribute** Data පුස්තකාල ගුණාංග ලැයිස්තුගත කර තෝරාගත් ඒවා සම්බන්ධිත පුස්තකාල අයිතමයට එක් කරයි; අවශ්‍ය නම් පසුව සමාගම් අයිතමයට පිටපත් කරන්න. ගුණාංගය තවම නැත්නම් එම තෝරකයේ **Create attribute** භාවිතා කරන්න. ගුණාංග පිටුවේ **Add value** පුස්තකාල අගයන් පිටපත් කරයි. **Create value** නව අගයක් පුස්තකාලයේ ලියා සමාගම් අයිතමයට පිටපත් කරයි.
