1. **Data → Services** විවෘත කරන්න.
2. සේවාවක් එකතු කර **time mode** (window vs duration) සහ **spaces** සකසන්න.
3. සුරකින්න. Calendar [events](/docs/calendar/create-event) මෙම සේවා වලින් තෝරයි.
4. සමාගම් සේවාව විවෘත කර **Attributes → Add attribute** තෝරන්න. පුස්තකාල සේවා පේළියක **Add** එම ගුණාංගය සමාගම් සේවාවට පිටපත් කරයි. **Add new attribute** Data පුස්තකාල ගුණාංග ලැයිස්තුගත කර සම්බන්ධිත පුස්තකාල සේවාවට එක් කරයි; අවශ්‍ය නම් පසුව සමාගම් සේවාවට පිටපත් කරන්න. ගුණාංග පිටුවේ **Add value** පවතින පුස්තකාල අගයන් පිටපත් කරයි. **Create value** නව අගයක් පුස්තකාලයේ ලියා සමාගම් සේවාවට සම්බන්ධ කරයි.

විස්තර පිටු reference counts පෙන්වයි (සේවාව භාවිතා කරන events හෝ අයිතම කීයද). පුස්තකාලයෙන් සේවාවක් එකතු කිරීම එම Data පුස්තකාල සේවාවට සම්බන්ධය තබා ගනී. **⋮** මෙනුවෙන් **Edit** (හෝ අංශ කාඩ්පතේ **Edit**) තෝරා නම, වේලාව, ටැග් සහ තවත් දේ වෙනස් කරන්න; wizard පුස්තකාල අගයන් පෙන්වන අතර ඔබ වෙනස් කළ ක්ෂේත්‍ර **Edited** ලෙස සලකුණු කරයි.

සමාගම් පරිපාලකයින් සේවාවේ **Prices & discounts** ටැබයෙන් විකුණුම් මිල සකසයි. **Prices** කාඩ්පතේ මිල එකතු කර එකක් සක්‍රීය මිල ලෙස සකසන්න. **Discounts** කාඩ්පතේ සක්‍රීය මිලෙන් අඩු වන ප්‍රතිශත වට්ටම් තිබේ. එක් වට්ටමක් **All time**, **Selected days**, හෝ **Selected range** (ආරම්භක දිනය සහ අවසන් දිනය) සඳහාත්, **Everyone** හෝ **Selected users** සඳහාත් අදාළ විය හැක. **Select user** පරිශීලක තේරීම විවෘත කරයි. සේවා ලැයිස්තුව සහ Overview අද සහ බලන පුද්ගලයාට ගැලපෙන වට්ටමෙන් පසු සක්‍රීය මිල පෙන්වයි.
