---

1. **Data → Services** විවෘත කරන්න.
2. සේවාවක් එකතු කර **time mode** (window vs duration) සහ **spaces** සකසන්න.
3. සුරකින්න. Calendar [events](/docs/calendar/create-event) මෙම සේවා වලින් තෝරයි.
4. සමාගම් සේවාව විවෘත කර **Attributes → Add attribute** තෝරන්න. පුස්තකාල සේවා පේළියක **Add** එම ගුණාංගය සමාගම් සේවාවට පිටපත් කරයි. **Add new attribute** Data පුස්තකාල ගුණාංග ලැයිස්තුගත කර සම්බන්ධිත පුස්තකාල සේවාවට එක් කරයි; අවශ්‍ය නම් පසුව සමාගම් සේවාවට පිටපත් කරන්න. ගුණාංග පිටුවේ **Add value** පවතින පුස්තකාල අගයන් පිටපත් කරයි. **Create value** නව අගයක් පුස්තකාලයේ ලියා සමාගම් සේවාවට සම්බන්ධ කරයි.

විස්තර පිටු reference counts පෙන්වයි (සේවාව භාවිතා කරන events හෝ අයිතම කීයද). පුස්තකාලයෙන් සේවාවක් එකතු කිරීම එම Data පුස්තකාල සේවාවට සම්බන්ධය තබා ගනී.

සමාගම් පරිපාලකයින් සේවාවේ **Price list** ටැබයෙන් විකුණුම් මිල සකසයි. මිලක් එකතු කර **All time** හෝ **Selected days** තෝරන්න. තෝරාගත් දින සඳහා ඉරිදා–සෙනසුරාදා තෝරා **Full day** හෝ **Specific time** (ආරම්භක සහ අවසන් වේලාව) තෝරන්න. ඉන්පසු **Everyone** හෝ **Selected users** තෝරන්න. සේවා ලැයිස්තුව සහ Overview වත්මන් දිනය, වේලාව සහ බලන පුද්ගලයාට ගැලපෙන මිල පෙන්වයි.
