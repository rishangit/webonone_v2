1. **Data → Products** විවෘත කරන්න.
2. **Add** තෝරා wizard සම්පූර්ණ කරන්න (details සහ variants).
3. විස්තර පිටුව බැලීමට නිෂ්පාදනයක් විවෘත කරන්න; එම wizard පියවරට යාමට කාඩ් මත **Edit** භාවිතා කරන්න.
4. ප්‍රභේදයක් විවෘත කර **Add** මගින් තොග කණ්ඩායමක් එක් කරන්න. එක් එක් කණ්ඩායමේ **තිත් තුනේ මෙනුවෙන්** ප්‍රමාණය, මිල, දින, හෝ සැපයුම්කරු **සංස්කරණය** කරන්න, නැතහොත් **සක්‍රිය ලෙස සකසන්න**.

Library නිෂ්පාදන Data හි තිබේ. තොග කණ්ඩායම් ඔබේ company catalog හි එම variant පිටුවට අයිති වේ. මෙනුව සැඟවී ඇත්නම් [company Data card](/docs/companies/data-services) මත නිෂ්පාදන සක්‍රිය කරන්න. පසුව [POS](/docs/sales-billing/pos) හි නිෂ්පාදන විකුණන්න.
