1. **Calendar → Events** විවෘත කරන්න.
2. **Add** තෝරන්න.
3. **service** (ඔබේ Data catalog හි සිට) තෝරා, වේලාව, staff, සහ අවශ්‍ය නම් recurrence සඳහා wizard පියවර පුරවන්න.
4. සුරකින්න.

Service **time modes** (window / duration) sessions සහ tokens ක්‍රියා කරන ආකාරය පාලනය කරයි. පළමුව [Data → Services](/docs/catalog/services) යටතේ services සාදන්න.
