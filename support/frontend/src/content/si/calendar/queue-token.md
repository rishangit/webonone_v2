1. ක්‍රියාත්මක **window-mode** session විවෘත කරන්න.
2. **Issue token** (හෝ session screen හි සමාන ක්‍රියාව) තෝරන්න.
3. ඉල්ලූ විට පාරිභෝගිකයා හඳුනාගෙන තහවුරු කරන්න.

token එක queue හි දිස්වේ. Call order අනුව සේවය කිරීමට call next/previous භාවිතා කරන්න. “token” සඳහා [glossary](/docs/glossary/glossary) බලන්න.

## Late check-in

පාරිභෝගිකයාගේ අංකය දැනටමත් පසුකර ගොස් ඇත්නම් (ඉහළ අංකයක් serving හෝ completed) සහ ඔවුන් ප්‍රමාදව check-in කළහොත්, screen හි **එම token අංකයම** රැඳේ. පද්ධතිය **call order** පමණක් සකසයි — දැනටමත් check-in වී රැඳී සිටින සැමට බලාපොරොත්තු වන රැඳීමේ කාලය ආසන්න වශයෙන් සමාන වන පරිදි. ඉහත check-in වූ අයෙකුට වඩා වැඩි වේලාවක් රැඳී සිටියේ නම්, ප්‍රමාදව පැමිණි අයෙකුට ඔවුන්ට පෙර call විය හැක.
