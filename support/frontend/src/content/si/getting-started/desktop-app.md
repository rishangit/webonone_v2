Desktop app යනු ඔබගේ පරිගණකයේ කවුළුවක WebOnOne ය. Browser එකේ කළ හැකි සියල්ල — calendar, people, catalog, messages, sales, සහ ඔබගේ website — මෙහිද ඇත.

## Install කරන්න

1. App හි **Settings → Basic Settings → Downloads** විවෘත කරන්න.
2. `WebOnOne-Setup.exe` සුරැකීමට **Windows සඳහා download** තෝරන්න.
3. Installer ධාවනය කර උපදෙස් අනුව ඉදිරියට යන්න.
4. Start menu හෝ desktop shortcut එකෙන් **WebOnOne** විවෘත කරන්න.

## Sign in වන්න

Browser එකේ මෙන්ම sign in වන්න: [email සහ password](/docs/getting-started/sign-in) හෝ එම විකල්පය පෙන්වන විට [Google](/docs/getting-started/sign-in-google).

කවුළුව වසා දැමූ පසුත් sign-in තබා ගනී. Internet සම්බන්ධතාවයක් තවමත් අවශ්‍යයි.

## Features website එක සමඟ sync වේ

අපි pages එකතු කරන විට හෝ app එක වෙනස් කරන විට නැවත install කිරීමට අවශ්‍ය නැත. Website යාවත්කාලීන කළ පසු, desktop app නැවත විවෘත කරන්න (හෝ refresh කරන්න) නව features බැලීමට.

Desktop කවුළුව සඳහා ඔබගේ කණ්ඩායම නව installer එකක් එවන්නේ නම් පමණක් නැවත install කරන්න.
