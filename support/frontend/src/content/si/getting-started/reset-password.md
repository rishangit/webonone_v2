audience: all

summary: "Forgot password භාවිතා කර, ඔබට යවන OTP ඇතුළත් කර, නව password එකක් සකසන්න."
---

1. Sign-in screen හි **Forgot password** තෝරන්න.
2. ඔබගේ ගිණුමේ email (හෝ ලබා දෙන්නේ නම් phone) ඇතුළත් කරන්න.
3. Email හෝ SMS මගින් ලැබෙන one-time code (OTP) විවෘත කරන්න.
4. Code එක ඇතුළත් කර, **new password** එකක් සකසන්න.
5. නව password සමඟ sign in වන්න.

Code එක කල් ඉකුත් වුවහොත්, එම screen වෙතින් නව එකක් ඉල්ලන්න. SMS බෙදාහැරීමේ ගැටළු ඇත්නම්, සමාගමේ SMS gateway online විය යුතුය — [Troubleshooting: SMS gateway](/docs/glossary/troubleshooting-gateway) බලන්න.
