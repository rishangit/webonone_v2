1. **WebOnOne** mobile app ස්ථාපනය කරන්න.
2. web හි භාවිතා කරන එකම email එකෙන් sign in වන්න.
3. ගිණුම් එකකට වඩා තිබේ නම් [ගිණුම තෝරන්න](/docs/getting-started/choose-account) (Super Admin, company owner, staff, හෝ default user).
4. web හි එකම left navigation සඳහා **menu** (ඉහළ වම) විවෘත කරන්න. ඔබේ වත්මන් ගිණුමට අදාළ අයිතම පමණක් පෙනේ.
5. **Profile** සඳහා header හි ඔබේ නම විවෘත කරන්න. ගිණුම් එකකට වඩා තිබේ නම් menu එකේ පහළින් switch කරන්න.

Company owners සහ Super Admins ට **SMS** ද පෙනේ. මෙම දුරකථනයේ SIM එකෙන් පණිවිඩ යැවීමට [mobile app SMS gateway ලෙස ස්ථාපනය කරන්න](/docs/communications/mobile-gateway) අනුගමනය කරන්න.

**Analytics**, Calendar, Sales, Data, Email, Payment, සහ Profile native screens වේ (web යෙදුමේ එකම දත්ත). **Design** තවමත් app තුළ හෝ browser එකේ web පිටුව විවෘත කරයි.
